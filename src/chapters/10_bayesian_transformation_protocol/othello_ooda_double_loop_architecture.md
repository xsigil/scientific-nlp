# オセロフィルター × OODAループ × ダブルループ学習：統合意思決定動態体系

## 1. 概念統合の全体像：なぜこの3つが不可分の関係にあるのか

ジョン・ボイド（John Boyd）が提唱した **OODA ループ** において、最も重要でありながら最も失敗しやすい急所が **「Orient（情勢判断）」** です。人間は観測（Observe）した情報を処理する際、過去の成功体験、恐怖、確証バイアス、組織の暗黙知によって情勢判断を致命的に歪めてしまいます。

**オセロフィルター** は、この Orient のブラックボックスを **「客観的デシバン加算」** によって完全に脱バイアス（De-bias）するリアルタイム・コプロセッサとして機能します。

さらに、クリス・アージリス（Chris Argyris）の **ダブルループ学習** を組み合わせることで、「日々のスコア加算（シングルループ）」にとどまらず、**「既存仮説が総崩れ・棄却されたときに、新たなアイデア・仮説を仮説空間へ注入し、基準仮説 $H_0$ や重みマトリックスそのものを書き換える（ダブルループ）」** 自己進化型の認知動態が完成します。

```

            ┌─────────────────────────────────────────────────────────┐
            │  ・全仮説の総崩れ・異常棄却（All Negative）検知         │
            │  ・新たな仮説・別解 H_new の創出と仮説空間の拡張        │
            │  ・基準仮説 H_0（日常・平時の定義）の再キャリブレート   │
            │  ・オセロフィルター重みテーブル W(H_k, D) の改訂       │
            └────────────────────────────┬────────────────────────────┘
                                         │ フィードバック（総崩れ・予測激震時）
                                         ▼
┌──────────────┐      ┌───────────────────────────────────┐      ┌──────────────┐      ┌──────────────┐
│   OBSERVE    │ ───▶ │              ORIENT               │ ───▶ │    DECIDE    │ ───▶ │     ACT      │
```

## 2. OODA 各フェーズにおけるオセロフィルターの振る舞い

### ① Observe（観測：事実の無色透明な抽出）

* **役割**: 一切の感情や解釈を交えず、生のエビデンス $D$（周波数、テキスト、行動ログ、発言など）を客観的事実として切り出す。
* **UBS / オセロフィルターの動作**:
  * スロットの直交化に基づき、独立した観測トークン（Element）を抽出。
  * `sort | uniq | hash` により、記述順序や重複ノイズを排除した決定論的ハッシュへ変換。

### ② Orient（情勢判断：オセロフィルターの真骨頂）

ボイドは「Orient とは遺伝的特質、文化的伝統、過去の経験、新しい情報の相互作用である」と説きました。人間が直感に頼るとここで「自分の見たい現実」を捏造します。

* **オセロフィルターによる強制脱バイアス**:
  1. **初期借金の明示**: 各仮説にベースレート（Prior）のペナルティ（例: レア事象なら $-20\text{ dB}$）を課す。
  2. **基準仮説 $H_0$ との比較**: 「他の可能性」ではなく、「平時の日常ノイズ（$H_0$）」と比較して何倍ありそうかだけをマトリックスから引く。
  3. **並行加算**: どの仮説にも肩入れせず、全仮説のバケツへ同時にスコアを足し込む。

### ③ Decide（意思決定：点差ルールによる冷徹なトリガー）

「迷い」や「優柔不断」を数理的に排除します。

* **トリガー条件**:
  * $\Delta\text{dB} < +6\text{ dB}$: 拮抗状態 $\to$ **「決定を保留し、追加の直交観測（Observe）を指示」**
  * $\Delta\text{dB} \ge +10\text{ dB}$（確信度 $\approx 91\%$）: 実用判定水準 $\to$ **「暫定勝者仮説として行動承認」**
  * $\Delta\text{dB} \ge +20\text{ dB}$（確信度 $\approx 99\%$）: 確定 $\to$ **「不可逆的な資源投入（全軍突撃・緊急遮断）」**
  * **【特異状態】全仮説がマイナス圏（All Negative: $\text{TotalDb}(H_k) \le -10\text{ dB}$）**:
    $\to$ **「用意した選択肢が全滅。直ちにダブルループを起動し、新規仮説の注入へ移行」**

### ④ Act（行動：世界への介入と反作用の観測）

決定された仮説に基づいて現実世界に介入します（例: ポートフォリオのリバランス、セキュリティ遮断、標的の追尾）。
介入によって新たな環境変化が生じ、それが次の **Observe** への入力となります。

## 3. シングルループ vs ダブルループ：仮説棄却と「アイデア注入」の力学

ここが本体系の最大の「味噌（Core）」です。既存の仮説がすべて否定されたとき、人間はパニックを起こすか現実逃避（バイアス）に走ります。ダブルループ学習は、それを**「新しいアイデアを仮説空間に注入するためのアルゴリズム的契機」**へと転換します。

```
┌────────────────────────────────────────────────────────────────────────┐
│ 【シングルループ学習】（盤面上の石の移動：問い「どれが一番マシか？」） │
│                                                                        │
│   観測事実 D が入る ──▶ オセロフィルターで足し算 ──▶ スコア最大の仮説で行動  │
│                                                                        │
│   ※ 既存の仮説選択肢の枠内だけで最も点数の高いものを探す。             │
└────────────────────────────────────────────────────────────────────────┘

          ▼ 既存の全仮説が否定（All Negative）または 行動結果の大激震（Surprise）

┌────────────────────────────────────────────────────────────────────────┐
│ 【ダブルループ学習】（盤面の拡張・アイデア注入：問い「前提の枠組みは正しいか？」）│
│                                                                        │
│   1. 【新規仮説 H_new の注入】:                                         │
│      「今テーブルにある仮説（A, B, C）は全部間違っている」             │
│      → 未知の第4の選択肢 H_new を立案し、新たなバケツを並べる。         │
│                                                                        │
│   2. 【基準仮説 H_0 の再キャリブレーション】:                          │
│      「平時・日常・ノイズ」とみなしていた前提環境そのものが変質したか？ │
│                                                                        │
│   3. 【証拠の決定力（マトリックス重み W）の改訂】:                      │
│      「かつて決定打だったシグナルが、陳腐化・無力化していないか？」    │
└────────────────────────────────────────────────────────────────────────┘
```

### レベル 1: シングルループ学習（Operational Loop）

* 既存の仮説空間 $\mathcal{H} = \{H_0, H_1, H_2\}$ を不変の前提として運用します。
* 入力されるエビデンスを淡々と足し算し、点差がついた仮説を実行に移します。

### レベル 2: ダブルループ学習（Epistemic / Creative Injection Loop）

ダブルループが発動する条件は極めて明確です。

1. **既存仮説の全滅・総崩れ（All Hypotheses Rejected）**:
   * 観測を重ねた結果、事前に用意していた仮説 $H_1, H_2, H_3$ のスコアがすべて $-10\text{ dB} \sim -20\text{ dB}$ に沈み、どれも現実を説明できなくなった。
   * $\to$ **「私たちの想像力の枠組みの外側に答えがある」**
   * $\to$ ブレインストーミング、現場ヒアリング、直交する異分野の知見を総動員して **新規仮説 $H_{\text{new}}$ を創出してバケツを緊急追加** する。

2. **結果の大激震（Prediction Error / Surprise）**:
   * $+20\text{ dB}$（確信度 $99\%$）で確実視して実行（Act）したのに、まったく逆の破壊的結果となった。
   * $\to$ 「証拠の解釈（重みマトリックス）」が狂っていたか、「基準（$H_0$）」が地殻変動を起こしている。
   * $\to$ 重み辞書をデバッグ・書き換え、基準仮説 $H_0$ を再定義する。

## 4. 組織・個人の意思決定における実践シナリオ

### 例：急変する市場における投資判断・事業撤退

| ループ階層 | アクション | 実務内容 |
| :--- | :--- | :--- |
| **Observe** | 観測 | 企業の有報テキスト、競合の値下げ、経営陣の退職ログを抽出。 |
| **Orient** | オセロフィルター | `Compounder`、`Moat`、`Distress` のバケツにデシバンを加算。 |
| **Decide** | 判定保留 | どの仮説もスコアが $-15\text{ dB}$ 以下になり、どれにも当てはまらない。 |
| **Double Loop (核心)** | **新規アイデア注入** | 「伝統的な財務分類が全滅した。**『第4の仮説：非連続なプラットフォーム転換による一時的先行投資（$H_{\text{Transformation}}$）』** ではないか？」という新しい見立て（アイデア）を注入し、新規バケツを設置して再計算する。 |
| **Act** | 介入 | 新規仮説の検証に必要な直交データ（特許出願動向・GitHubリポジトリ活動）をピンポイントで追加観測し、迅速にポジションを構築する。 |

## 5. 本体系の哲学的・工学的帰結

* **「手詰まり（Dogmatism）」の数学的破壊**:
  人間は選択肢が尽きると、すでに破綻した仮説に無理やりしがみつきます。本体系では全仮説のスコアがマイナスに沈んだ瞬間、システムが冷徹に「手持ちの仮説は全滅である」と宣告するため、**新しいアイデアを生み出さざるを得ない強制的な知的ジャンプ**が生まれます。

* **最速の OODA ループ**:
  掛け算のない「整数デシバン加算」により、現場の作業員やアナリストがミリ秒オーダー（暗算なら数秒）で Orient を完了し、競合他社より圧倒的に速いテンポで OODA を回せます。

* **知的有機体への進化**:
  日々のシングルループで現場が素早く動き、蓄積された「棄却とサプライズ」が自動的にダブルループを刺激して、新しい仮説と研ぎ澄まされた重み辞書が組織に蓄積されていきます。

オセロフィルターは単なる計算表ではなく、**「既存の枠組みが壊れたときに、新しいアイデアを注入して自己更新し続ける知性」を駆動するための計算論的コア**である。
