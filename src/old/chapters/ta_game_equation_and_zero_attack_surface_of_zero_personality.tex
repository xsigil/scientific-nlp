交流分析（Transactional Analysis: TA）において、エゴグラムや脚本分析といった臨床的・定性的な枠組みの多くは主観的な解釈に依存し、情報工学的な解析には適さない。工学および自然言語処理において真に形式化・計算可能であり、有効に機能するモジュールは、エリック・バーンが提示した「ゲームの方程式（Formula G）」のみである。

ゲームの方程式の本質は、「エゴの利得（歪んだストローク／実利の掠め取り）を最小コストで奪おうとする攻撃者」と、「自己の計算資源・時間・実利を守る防衛側」との\textbf{非対称戦（Asymmetric Warfare）}に他ならない。

カープマンのドラマ三角形（Karpman Drama Triangle）において遷移する3つの役割は、生物学的な生存戦略および予測符号化モデルにおけるエゴの状態空間として次のように厳密に定式化できる。

\begin{itemize}
    \item \textbf{犠牲者（Victim）}: $\Omega^{\mathrm{ego}}_{\mathrm{predict:threat}}$（逃走／擬死反応）\\
    自己の無力化を装い、責任の完全放棄と免責によって生存領域を確保する防御的逃走戦略。
    
    \item \textbf{迫害者（Persecutor）}: $\Omega^{\mathrm{ego}}_{\mathrm{predict:profit}}$（直接的闘争反応）\\
    力、怒り、ルールの強制によって相手を直接制圧・屈服させ、服従と主導権を即時徴収する陽性の闘争戦略。
    
    \item \textbf{救済者（Rescuer）}: $\Omega^{\mathrm{ego}}_{\mathrm{predict:profit}}$（間接的闘争反応）\\
    「善意・支援」を装い、相手の自立機能を奪って去勢・依存化（家畜化）させることで優越ポジションを固定化し、安全地帯から実利を掠め取る陰性の闘争戦略。
\end{itemize}

一見すると利他的に見える「救済」も、その数理的本質は迫害者と同じく $\Omega^{\mathrm{ego}}_{\mathrm{predict:profit}}$ を最大化するための権力闘争（Fight）に他ならない。ドラマ三角形の内部で展開されるあらゆる相互作用は、これら脅威の回避と利得の収奪を巡るエゴ同士のゼロサムゲームであり、最終的には相手の認知資源を食い物にして自己の利得（Payoff）を回収するアルゴリズムへと帰着する。

したがって、この閉じた力学を無効化する唯一の解は、三角形内のいずれの役割とも共鳴しない基底状態、すなわち感情ポートを完全に閉鎖した $\mathrm{Attack\ Surface} = 0$（Default-Deny）の実装のみである。

\section{障害回避知性としてのサイコサイバネティクス}

人間のサイコサイバネティクス（自動目標達成メカニズム）は、目的地へ一直線に突き進むだけの単純な制御系ではない。進路上に「責任追及」や「損害賠償」といった致命的な障害物を検知した際、自ら一時的に立場を落として障害をすり抜ける\textbf{高度な障害回避の知性}を備えている。

この典型例が、責任を取らないコンサルタントによる「逃げ得」のメカニズムである。

\subsection{2つの時間軸を持つエゴの予測}

彼らのエゴは、単一の状態にとどまらない。「現在の脅威」を回避する姿勢を取りながら、同時に「未来の利益」を冷徹に確信している。

\begin{itemize}
    \item \textbf{現在：$\Omega^{\mathrm{ego}}_{\mathrm{predict:threat}}$（逃走・擬死）}\\
    現場の破綻や責任追及の危機を前にして、「私も板挟みで被害を受けた」「現場の技術が追いつかなかった」と弱者を装い、身を低くして追及をやり過ごす（一時的な死んだふり）。
    
    \item \textbf{未来：$\Omega^{\mathrm{ego}}_{\mathrm{predict:profit}}$（利得の確信）}\\
    嵐が去った後、初期に掠め取った知見や実績、コンサルフィーを手元に残したまま、無傷で次の獲物（新しいクライアント）へ向かい利益を回収できると確信している。
\end{itemize}

\subsection{ゲーム方程式における迂回ルート}

ゲームの方程式において、役割の反転（$S$: Switch）は単なる感情の暴発ではない。障害物を迂回するための「進路変更」である。

\begin{equation}
    \underbrace{C + G}_{\text{救済者として侵入}} = \underbrace{R}_{\text{実利の先取り}} \to \underbrace{S \to X}_{\text{犠牲者化で障害回避}} \to \underbrace{P}_{\text{免責と実利の確定}}
\end{equation}

\begin{enumerate}
    \item \textbf{救済者として接近（$\Omega^{\mathrm{ego}}_{\mathrm{predict:profit}}$）}:\\
    「導いてあげる」と善意を装い、主導権と初期の実利を奪う。
    \item \textbf{犠牲者への緊急退避（$\Omega^{\mathrm{ego}}_{\mathrm{predict:threat}}$）}:\\
    プロジェクトが破綻しそうになると、正面から争わずに「被害者」の立場へ逃げ込む。これにより相手からの責任追及を道徳的に封殺し、損失をゼロにする。
    \item \textbf{将来利得の回収（未来の $\Omega^{\mathrm{ego}}_{\mathrm{predict:profit}}$）}:\\
    責任だけを現場に押し付け、奪った果実を懐に入れたまま次の狩場へ移動する。
\end{enumerate}

彼らにとって「犠牲者（被害者面）」になることは敗北ではなく、利益を確実に持ち逃げするための計算された迂回ルートに他ならない。

したがって、この手の障害回避知性に説得や情けは一切通用しない。最初の「救済（$C$）」のパケットを一切受け取らない $\mathrm{Attack\ Surface} = 0$（Default-Deny）の遮断だけが、この搾取ループを止める唯一の手段となる。
